# 💻 IGCSE Computer Science — Algorithms

An **algorithm** is a step-by-step method for solving a problem.

## 🔹 Sequence

Instructions run in order.

```text
INPUT name
OUTPUT "Hello " + name
```

## 🔹 Selection

Used to make decisions.

```text
IF age >= 18 THEN
    OUTPUT "Adult"
ELSE
    OUTPUT "Child"
ENDIF
```

## 🔹 Iteration

Used to repeat instructions.

```text
FOR i ← 1 TO 5
    OUTPUT i
NEXT i
```

## 🔹 Variables

Variables store data.

```text
score ← 100
name ← "Ali"
```

## 🔹 Operators

| Operator | Meaning          |
| -------- | ---------------- |
| `+`      | Add              |
| `-`      | Subtract         |
| `*`      | Multiply         |
| `/`      | Divide           |
| `MOD`    | Remainder        |
| `DIV`    | Integer division |

Example:

```text
17 MOD 5 = 2
17 DIV 5 = 3
```

## 🔍 Searching

**Linear search** checks items one by one.

`4, 8, 12, 20`

Search for `12`:

`4 → 8 → 12 ✓`

## 🔃 Sorting

Sorting puts data into order.

`7, 2, 9, 4`

↓

`2, 4, 7, 9`

**Bubble sort** is a common sorting algorithm.

## 📋 Trace Tables

Used to follow changing values.

```text
x ← 5
x ← x + 3
x ← x × 2
```

Final value:

`x = 16`

## ⭐ Remember

**Sequence** → order
**Selection** → decision
**Iteration** → repetition
**Variable** → stores data
**Search** → finds data
**Sort** → orders data
